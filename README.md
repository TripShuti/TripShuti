<p align="center">
Мене звуть Сашко, косплею сісадміна та програміста, веду свій homelab <img src="https://media1.giphy.com/media/2zeji2UedvZzvIZ45N/giphy.gif" width="8%"> , по трошки вчуся програмувати штуки котрі в першу чергу цікаві або потрібні мені самому,
  дяка ШІ з цим дуже допомгає.
  Це не про пошук нового покликання чи професії, вся ця тематика стала просто цікавим хобі, а гітхаб та спільнота(хоча не сказати що активний участник, скоріш спостерігач) просто соцмережою де можна приємно провести час.
</p>
